# JSON Table Viewer

React + TypeScript SPA — загрузка JSON с прогрессом и отменой,
виртуализированная таблица, поиск с подсветкой.

## Запуск

```bash
npm ci
npm run dev
```

Дев-сервер поднимется на http://localhost:5173.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер с HMR |
| `npm run build` | проверка типов + прод-сборка в `dist/` |
| `npm run preview` | локальный просмотр прод-сборки |
| `npm run typecheck` | проверка типов без сборки |
| `npm run lint` | ESLint |
